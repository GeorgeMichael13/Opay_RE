Overview

This project is a modern redesign of the OPay homepage, created to demonstrate my frontend development skills and my approach to designing fast, responsive, and user-friendly web experiences.

Rather than changing the core identity of the brand, the goal was to explore how the homepage could be refreshed with improved visual hierarchy, smoother interactions, cleaner layouts, and a modern UI while maintaining the familiarity of the OPay experience.

Technologies Used

- Next.js

Features

- Fully responsive design
- Modern landing page UI
- Smooth animations powered by Framer Motion
- Optimized images using Cloudinary
- Clean and reusable component architecture
- Mobile-first development approach
- Fast performance and optimized loading
- Accessible layout and intuitive navigation

Why I Built This

As a frontend developer, I enjoy redesigning real-world products as a way to sharpen my UI/UX thinking and engineering skills.

This project challenged me to think beyond simply recreating an existing interface. Instead, I focused on:

- Improving user experience
- Creating engaging animations
- Building reusable UI components
- Writing maintainable TypeScript code
- Delivering a production-quality frontend

Getting Started

Clone the repository:

git clone https://github.com/GeorgeMichael13/Opay_RE.git

Install dependencies:

npm install

Run the development server:

npm run dev

Build for production:

npm run build
